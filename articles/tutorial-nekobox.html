🤖 Android 平台开源神器 NekoBox 零基础安装与订阅配置教程

发布日期：2026-09-16 阅读时间：约 7 分钟 (1220 字) 适用系统：Android 8.0 及以上

随着原版 Clash for Android (CFA) 的停止维护，NekoBox (猫盒) 已迅速成长为安卓端最受欢迎的开源科学上网工具。基于 sing-box 内核的强大底层，NekoBox 原生支持 VLESS、Hysteria2、TUIC v5 等先进代理协议。本文将为您详细拆解 NekoBox 的下载、订阅导入与优化设置。

一、软件下载与架构选择

在安卓设备上使用 NekoBox，请确保从可靠渠道获取安装包：

1. GitHub Release 官方版本

访问 NekoBox GitHub 开源发布页。大多数现代安卓手机（如高通骁龙、天玑处理器）请下载 NekoBox-arm64-v8a.apk；若使用的是较旧的 32 位设备，请下载 armeabi-v7a 版本。安装时请勾选允许“未知来源应用安装”。

二、机场订阅链接导入步骤

完成安装并打开 NekoBox 后，可以通过以下流程轻松导入代理节点：

步骤 1：复制订阅 URL

登录您的服务提供商（例如云图机场或宝云）后台，找到通用订阅链接或 Sing-box 订阅链接并复制到手机剪贴板。

步骤 2：添加订阅分组

打开 NekoBox，点击左上角三条杠菜单，选择「分组」选项。点击右上角「+」号，输入分组名称（如“云图专线”），在【分组类型】中选择 订阅，随后将剪贴板中的链接粘贴至【订阅链接】栏并保存。

步骤 3：更新与获取节点

回到分组列表卡片，点击右侧的刷新按钮（或右上角菜单中的更新订阅）。稍等数秒，系统将自动拉取最新的代理节点列表。

三、节点选择与分流连接

1. 节点真连接延迟测试

返回软件首页，点击右上角⚡图标进行「TcpPing」或「URL Test (真连接测试)」，以便剔除无效节点，选出当前延迟最低的优质线路。

2. 启动代理与授权

点击您心仪的节点，然后点击右下角的▶ 运行按钮。首次运行时，系统将弹出“构建 VPN 连接”提示框，点击允许即可开始顺畅上网。

四、常见问题排查与优化技巧

  • 开启应用分流（Split Tunneling）：在侧边栏设置中选择「应用代理」，您可以指定仅让外网软件（如 Telegram、YouTube）走代理，国产生命周期软件（如微信、淘宝）直连。
  • 耗电量优化：在设置中关掉不必要的日志输出（LogLevel 设置为 Warning 或 Error），可显著降低后台运行时的 CPU 占用。
