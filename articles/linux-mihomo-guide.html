🐧 Linux科学上网教程：mihomo命令行翻墙与机场订阅导入（2026）

发布日期：2026-09-16 阅读时间：约 7 分钟 (1180 字) 适用环境：Linux VPS / Ubuntu / Debian / WSL / 无桌面环境

在 Linux 服务器或 WSL 环境中，敲下 git clone 进度条纹丝不动，docker pull 频繁连接超时，或者使用 pip install 遭遇报错 Refused 是许多开发者常遇到的痛点。Linux 没有图形界面，而经典的原版 Clash（Dreamacro/clash）在 2023 年 11 月已被作者删库停更。2026 年在 Linux 上科学上网的**正确姿势就是采用 mihomo 命令行内核结合机场订阅**。

一、避坑澄清：为什么要选择 mihomo？

原版 Clash 官方仓库停更后，所有基于旧版安装包的教程链接均已失效。**mihomo**（即原 Clash Meta 内核）是正统继承者，不仅完美兼容旧版的规则与 YAML 配置文件，还增加了对 Hysteria 2、VLESS 等下一代现代化代理协议的深度支持，是目前 Linux 无桌面环境下的绝佳首选。

二、mihomo 命令行极速部署流程

1. 查看系统架构并下载二进制文件

首先通过终端查询架构并前往 mihomo 官方 Releases 仓库下载最新稳定版：

uname -m
# x86_64 对应 amd64，aarch64 对应 arm64
2. 解压配置与导入机场订阅

将解压后的二进制文件赋予执行权限并移至 /usr/local/bin/mihomo。接着将从机场后台复制的 Clash 订阅链接下载为本地 config.yaml 配置文件：

curl -o ~/.config/mihomo/config.yaml "你的机场Clash订阅链接"

三、配置 Systemd 服务实现开机自启

为了保障服务器重启后代理不中断，可以通过配置 Systemd 将 mihomo 托管为系统守护进程：

[Unit]
Description=mihomo Daemon, A rule-based proxy in Go.
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/mihomo -d /etc/mihomo
Restart=always

[Install]
WantedBy=multi-user.target

四、终端、Git 与 Docker 环境变量挂载

启动服务后，默认代理端口通常为 7890。可以通过设置环境变量一键让终端命令走代理加速：

export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890

五、总结与建议

通过 mihomo + 订阅的方式，仅需数分钟即可为无桌面 Linux 服务器打通高速出海通道，彻底解决依赖下载慢、Docker 镜像拉取超时等难题。
