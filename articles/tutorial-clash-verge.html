🪟 Windows 平台 Clash Verge Rev 从零开始安装与订阅导入指南

发布日期：2026-09-16 阅读时间：约 6 分钟 (1050 字) 适用系统：Windows 10 / 11 (64-bit)

在当前 Windows 平台上，Clash Verge Rev 已成为取代老旧客户端的最主流科学上网代理软件。它基于 Tauri 框架打造，内存占用更低、支持最新的 Mihomo (Clash Meta) 内核，完美支持 VLESS、Hysteria2 以及各种复杂的规则分流配置。

一、软件下载与安装准备

建议始终从官方开源 GitHub Release 页面下载最新安装文件，避免使用经过篡改的第三方打包软件：

1. 安装包选择提示

一般用户请选择 Clash.Verge_x64-setup.exe 安装程序；若系统提示缺少 Webview2 运行时，请跟随微软官方指引补全系统组件。

二、导入机场订阅链接

完成安装并启动 Clash Verge Rev 后，请遵循以下四个简单步骤完成订阅添加：

步骤 1：复制机场订阅链接

登录您所使用的优质加速机场后台（如云图机场或极速Cloud），找到 Clash 专属订阅复制按钮。

步骤 2：添加配置并刷新

在 Clash Verge 左侧导航进入「订阅 (Profiles)」页面，将复制的 URL 粘贴至上方地址框中，点击右侧的「导入 (Import)」按钮。导入成功后，卡片将显示节点总数与更新时间。

步骤 3：选择代理模式与节点

点击左侧「代理 (Proxies)」菜单。建议新手用户保持「规则 (Rule)」分流模式，在此模式下，国内网站自动直连，国外受限网站自动通过代理中转。

步骤 4：开启系统代理与开机自启

回到「设置 (Settings)」页面，打开「系统代理 (System Proxy)」开关。若需要开机自动后台运行，可同步勾选「开机自启 (Auto Launch)」。

三、常见故障排查 (Troubleshooting)

  • 开启系统代理后无法上网？：请检查防火墙是否阻挡了 Clash 进程，或在设置中重置 TAP/TUN 虚拟网卡。
  • 节点延迟全显示 Timeout？：确认系统时间是否与标准北京时间同步，相差超过 30 秒将导致 TLS 握手失败。
