🌐 深入浅出解析现代网络代理架构：从 Socks5 到 TUN 模式

发布日期：2026-09-16 阅读时间：约 6 分钟 (1080 字) 所属分类：隐私安全与前沿技术

在使用 Clash 或 NekoBox 时，我们常听到正向代理、透明代理、TUN 虚拟网卡等专业术语。理解网络数据包在电脑与服务器之间的流转路径，有助于排查无法上网或 DNS 泄漏问题。

一、正向代理与反向代理的区别

1. 正向代理 (Forward Proxy)
客户端（您的电脑）主动通过代理服务器去访问目标网站，代理服务器代表客户端发出请求。我们日常使用的机场即属于正向代理。
2. 反向代理 (Reverse Proxy)
服务器端（如 Cloudflare）代表源站接收互联网连接，客户端并不知道真正的源站服务器 IP 地址。

二、系统代理 (HTTP/Socks5) 与 TUN 模式的区别

  • 系统代理 (System Proxy)：仅仅修改操作系统的 HTTP/HTTPS 代理环境变量。只有遵循该变量的应用（如 Chrome 浏览器）会走代理，而游戏客户端、命令行终端等通常会绕过代理。
  • TUN 模式 (Tun Mode)：在操作系统中创建一张虚拟三层网卡（TUN Device），将系统所有 IP 数据包强行接管拦截。不论软件是否支持代理，都会被强制分流转发，实现全自动全局代理。
