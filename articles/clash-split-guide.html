🔀 Clash 分流详解：开了代理国内网站变慢？怎么让国内流量直连、国外走代理（2026）

发布日期：2026-09-16 阅读时间：约 7 分钟 (1210 字) 核心概念：智能分流 / 规则模式 / GEOIP / 策略组

许多刚接触代理客户端的新手常常遇到这种困惑：开启代理软件之后，访问 Google 或 YouTube 非常顺利，但打开百度、淘宝或 B 站等国内网站却变得异常缓慢，甚至提示加载失败。原因就在于没有正确配置**智能分流模式**。分流是 Clash 区别于经典一键 VPN 的核心优势，本文将大白话拆解分流原理与模式选择。

一、什么是分流？一句话讲清

分流，就是**给流量按规则指路**：哪些流量走代理出国、哪些流量直接直连留在国内、哪些广告流量直接屏蔽。如果不做分流而使用全局代理，访问国内网站相当于从北京发出的请求绕道美国服务器再返回国内，不仅速度奇慢，还会白白消耗宝贵的机场套餐流量。

二、三大路由模式区别与选型法则

1. 规则模式 (Rule) —— 日常默认选它！

客户端会自动根据规则列表进行判断：访问国内目标走 Direct 直连（不耗流量、速度飞快）；访问境外目标才自动走 Proxy 节点中转。

2. 全局模式 (Global) —— 仅调试排查使用

所有网络流量强制无差别走代理节点，极易导致国内应用卡顿，不适合日常常驻开启。

3. 直连模式 (Direct) —— 等同于暂停代理

所有流量都不经过代理，相当于临时关闭了代理功能，适合临时测试网络原生连接状态。

三、分流的核心规则骨架

在底层 YAML 配置文件中，智能分流主要依赖于国内 IP 库与域名规则集：

rules:
- GEOIP,CN,DIRECT # 匹配中国大陆 IP 自动直连
- GEOSITE,google,PROXY # 谷歌系服务自动走代理
- GEOSITE,youtube,PROXY # YouTube 自动走代理
- MATCH,PROXY # 其余未匹配到的境外网站默认兜底走代理

四、总结与使用建议

导入任何机场订阅后，第一件事就是确认客户端主页上的路由模式是否处于**“规则模式 (Rule)”**。做好分流不仅能保证国内网站秒开，还能为你节省一半以上的套餐流量。
