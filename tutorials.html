全平台 科学上网客户端 配置指南

图文详解，从零开始，10 分钟搞定订阅导入与分流规则配置，覆盖 Windows, iOS, Android, macOS 及 Linux。

🪟

Windows · Clash Verge Rev

最主流 Windows 客户端 · 支持规则分流
1前往 GitHub 下载最新版 Clash Verge Rev 安装包
2安装完成后，点击左侧栏「订阅」菜单
3粘贴机场提供的订阅链接，点击导入与更新
4切换到「代理」选择合适节点，开启系统代理
查看详细图文教程 →
🍎

iOS · Shadowrocket (小火箭)

iOS 最流行代理工具 · 需外区 Apple ID
1切换至美区/港区 Apple ID，在 App Store 购买下载
2打开 App，点击右上角「+」号添加配置
3类型选择 Subscribe，粘贴机场订阅链接
4首页开启连接开关，允许添加 VPN 权限即可
查看详细图文教程 →
🤖

Android · NekoBox

开源免费 · 支持 Hysteria2 / VLESS 等协议
1下载安装 NekoBox APK 并给予基本权限
2点击右上角菜单 → 「从剪贴板导入」
3或在「订阅」分组添加机场 URL 链接
4选中可用节点，点击右下角 ▶ 按钮启动连接
查看详细图文教程 →
🖥️

macOS · ClashX Meta

Mac 菜单栏常驻工具 · 快速切换节点
1下载安装 ClashX Meta，打开配置托管页面
2粘贴机场订阅链接，点击「更新」下载节点
3勾选「设置为系统代理」并选择节点模式
查看详细图文教程 →
📱

iOS · ClashMi

iOS 新兴免费客户端 · 原生支持 Clash 内核
1App Store 搜索 ClashMi 免费下载安装
2点击底部「订阅」 → 右上角「+」号
3选择「从 URL 导入」并粘贴机场链接
4回到首页开启 VPN 开关即可畅快使用
查看详细图文教程 →
💻

Cursor · AI 编程代理配置

自定义中转 API 密钥 · 低成本畅快编程
1打开 Cursor 设置 → Models 选项卡
2启用 OpenAI API Key，填入中转 Key 与 Base URL
3添加 claude-3-5-sonnet 模型即可体验高效率写代码
